新增原生 Hysteria2、Xray、sing-box 的可选访问记录上报，可对接 ClickHouse 和 across_log-panel。
同时修复长连接在连续在线统计窗口中漏报、以及在线上报 API 失败被当成成功的问题。

- 三核心统一发送用户 UID、节点 ID、来源 IP、目标域名/IP、端口、TCP/UDP 和 UTC 时间。
- 默认关闭；上报地址、账号、数据库/表可配置，无固定服务器和凭据。
- 单 worker、有界队列和批次，不阻塞转发、不落盘访问内容；失败、丢弃和未知结果可查。
- 在线设备以连接存续及 IP 引用计数统计，每 60 秒心跳，保留流量门槛和失败后的离线重报。
- 新增隐藏密码输入的 `V2bX accesslog configure`，保留原有节点配置；发行包包含升级及失败回滚脚本。

配置与升级：[部署说明](https://github.com/rmomo5285-droid/V2bX/blob/v0.1.2/docs/accesslog.md)。

旧节点一次升级并配置（Linux amd64/arm64 标准 systemd 安装）：

```bash
curl -fsSLo /root/v2bx-upgrade-accesslog.sh https://raw.githubusercontent.com/rmomo5285-droid/V2bX/v0.1.2/scripts/upgrade-accesslog.sh && bash /root/v2bx-upgrade-accesslog.sh --version v0.1.2 --endpoint https://logs.example.com/ingest --username v2bx_writer
```

将示例上报地址和账号替换为自己的部署，按提示输入 writer 密码。
首次运行将校验发行包并备份旧程序及上报配置，保留主配置、证书和节点设置。

验证覆盖全量 Go 测试、race/vet、三核心采集到 HTTP 发送、队列故障和升级回滚。
发送器另完成了 HTTPS → ClickHouse → 面板查询联调。生产节点仍需先小批升级观察。

原生 Hy2 和 sing-box UDP 会话后续逐包改变的目标未逐包记录。
