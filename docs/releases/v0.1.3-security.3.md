# v0.1.3-security.3

Xboard compatibility improvements now retain failed accounting batches, support
v2 and machine-token authentication for explicitly configured nodes, distinguish
empty user lists from HTTP 304, allow idle nodes to start, preserve device counts
on alive-query failures, and retry snapshots after failed core updates. Background
task generations have isolated stop signals. See `docs/upstream-integration.md`
for source references, configuration, tests and delivery limitations.

Go 1.27.3 rebuild of V2bX v0.1.2 with default MPTCP disabled, current Xray and
REALITY forks matching the v2node update on 2026-11-02, Hysteria2 2.13.0 and
updated security-sensitive Go dependencies. Native Hysteria2 UDP target changes
now propagate to the configured outbound ACL; fragmented sniffing and panel
rules have regression coverage. An offline systemd upgrade helper verifies
SHA-256, backs up the binary and rolls back on initial service failure.

The sing-box QUIC fork also contains a source backport of the upstream
CVE-2026-40898 fix, limiting decoded HTTP/3 trailer fields. Dedicated tests
cover expansion, validation and early termination. Renamed forks and local
replacements are not reliably covered by automated upstream CVE matching.
The remaining Hysteria `GO-2026-5288` scanner finding has no database fix
version; V2bX now caps each UDP sniff operation at 64 KiB and rejects larger
inputs before they reach the parser. This is a bound, not a claim of upstream
resolution.

The sing-box panel fork is preserved as pinned source with one REALITY private
key compatibility patch. Go 1.27 builds require `http2legacy`; CI/Docker/release
commands include it. See `third_party/README.md` for provenance and limits.

Check existing configs: the current Xray removed legacy transport headers
`srtp`, `tls`, `utp`, `wechat-video` and `wireguard`, Shadowsocks `none`/`plain`,
and the `DisableIVCheck` option. TLS/REALITY transports remain available.

This is an application mitigation, not a Linux kernel fix. Install the vendor
kernel update for CVE-2026-98432 and boot it. Until then, disable MPTCP at the
host/network-namespace level and restart existing listeners. Explicit MPTCP
options and GODEBUG overrides bypass the build default. See
`docs/security-mptcp.md`.

Release archives retain their existing platform names and include SHA-256
sidecars. `update-security.sh` downloads this fixed release, verifies the archive
and rollback helper, then upgrades an existing standard systemd installation.
Check the entry script against its independently confirmed release checksum
before executing it. Connections are interrupted by the service restart;
configuration, certificates and geodata are preserved. See
`docs/security-upgrade.md` for supported layouts and rollback limits.

Validation covers a mock Xboard panel and real localhost listeners in one
process with clients and TCP echo. CI gates publication on the full suite,
QUIC regressions, focused race checks, 32/128-client stability workloads, five
Hysteria2 churn rounds on the same node, three 180-second natural idle memory
observations, updater/rollback checks and vet. Each architecture is compiled
from the exact validated tag. All draft assets are downloaded and checked
before the release is made public. No production server was connected.

The 128-client persistent workload starts all independent transports together.
Short-connection churn uses a global admission clock. Xray/sing open new TCP
connections; each Hysteria2 client retains its QUIC session while repeatedly
opening/closing TCP streams. JSON distinguishes session_mode, TCP connections
and successful_quic_sessions. Every error still fails these stability tests.
Natural idle snapshots keep the node and authorization active, with no forced
GC until after the 180-second sample. RSS includes the clients and echo.

Known capacity limits are retained: earlier Windows tests refused 3 of 128
Hysteria2 handshakes; an instrumented single-thread run showed a full 32-entry
QUIC accept queue. Linux full-session churn also refused connections, including
10 failures in run 41481256146 and failures in all five repeated rounds in run
41483389723. Both .1 and .2 tags were stopped and never published. One repeated
round also failed the successful-exchange accounting comparison; that failed
result is preserved. These overload limits have not been repaired or hidden
by increasing the production accept queue or adding client retries.

To reproduce full-QUIC-session churn, set V2BX_STRESS_FRESH_QUIC=1. To also
restore periodic synchronized worker bursts, set V2BX_STRESS_BURST_CHURN=1.
Normal protocol multiplexing validation is not a promise of unlimited TLS/QUIC
handshake capacity, maximum users, WAN bandwidth, or hours-long leak freedom.
See docs/stress-testing.md for the workload and failure evidence.

Android uses the Android-only -checklinkname=0 flag required by anet's documented
Go 1.23+ workaround. Other platforms retain default linker checks. Android and
other non-Linux platforms were cross-compiled only; device runtime validation,
Docker builds, real production-panel behavior and all client configurations
are outside this acceptance. The preserved scanner findings and legacy Xray
configuration removals above also remain relevant.
